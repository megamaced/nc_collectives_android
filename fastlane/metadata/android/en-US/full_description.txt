An unofficial native Android client for the Nextcloud Collectives app — wiki-style markdown notebooks hosted on your own Nextcloud server.

Features:

* Five tabs: Home, Collectives, Search, Favorites and Alerts, each keeping its place. Phones get a bottom navigation bar; wide screens get a navigation rail.
* Home, from the local cache so it works offline: edits waiting to sync or in conflict, new alerts, and cards for the pages you opened recently, pages changed since you read them, recently updated pages and your own edits, each with See all for the full list. Plus the tags across every collective.
* Alerts: mentions of you, and changes to pages in collectives set to notify you. Dismissing one clears it on the server too. In-app only: no system notifications.
* Collectives and nested page trees, sorted A–Z, Z–A, newest or oldest first. Pages can also follow the custom order shared with the web app, and be dragged within their parent.
* Markdown rendering with images, links, task lists, tables, syntax-highlighted code blocks and Nextcloud Text callouts (INFO / WARN / ERROR / SUCCESS). [[Page Name]] wikilinks and relative .md links open in the app.
* Each page lists its subpages, the pages that link to it, and its headings.
* View-first, with a floating Edit button; the bars slide away as you scroll. Two editors: a native markdown editor with a formatting toolbar and a preview, which works offline (the default), and a collaborative editor backed by Nextcloud Text (beta — real-time editing with others) when the server offers it and you're online.
* Offline reading and editing. Edits made offline are queued, and each is sent against the version it was written from: when the server reports that someone else changed the page meanwhile, your text is kept as a draft beside theirs and you choose which wins.
* Search across every collective through Nextcloud's unified search, with recent searches and tags offered before you type.
* Favorites, grouped by collective.
* Page tags, emoji, rename, move and duplicate; trash and restore, with Undo. Create collectives, change their emoji, and trash, restore or delete them.
* Attachments: inline images, and uploads from the camera or gallery.
* Quick capture from any app's Share menu: text, links, or images.
* Several Nextcloud accounts, switched without signing out.
* Light, Dark or System theme, and a page text size for pages and both editors.
* Background sync every 1, 6 or 12 hours, daily, or never; pull to refresh; and Sync now.
* Manual update check for installs from GitHub: Settings → About asks GitHub for the latest release only when you tap it. F-Droid users can ignore it — F-Droid updates the app as normal.

Requirements:

* Android 10 (API 29) or newer.
* A Nextcloud instance with the Collectives app installed, served over HTTPS. Plain http:// server addresses are refused.

Signing in uses Nextcloud Login Flow v2: you approve the app in your browser, and your server gives it a device-scoped app password. The app never sees your account password, and you can revoke the device at any time from your Nextcloud security settings.

Privacy:

* The app talks only to the Nextcloud server you configure. The one exception is the update check, which contacts api.github.com only when you tap it, on a separate HTTP client that never carries your Nextcloud credentials.
* No Google Play Services. No Firebase. No analytics. No telemetry. No crash reporters. No advertising IDs.
* The app password is stored in EncryptedSharedPreferences (Tink-backed). Signing out deletes it, along with every cached page and setting.
